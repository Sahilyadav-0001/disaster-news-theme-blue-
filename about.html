📋 Project Overview

Disaster News is a full-stack web application that provides real-time monitoring of natural disasters worldwide. The platform integrates data from multiple sources including USGS (earthquakes), NASA FIRMS (wildfires), and other global monitoring systems to deliver comprehensive disaster information.

Built with modern web technologies including Node.js, Express, Leaflet.js, and Chart.js, the platform features an intuitive dashboard with interactive maps, real-time charts, live feeds, and AI-powered predictions.
